현재 프로젝트의 지연 동기화를 처리한다. 평소엔 연동 파일을 즉시 고치지 않고
SYNC-PENDING.md에 대기만 기록해 두었다가, 이 명령으로 한 번에 전파·재빌드한다.

인자 $ARGUMENTS — (없음)=전부 / status=목록만(고치지 않음) / <이름>=그 항목만.

절차:
1. 루트 SYNC-PENDING.md 읽기. 없거나 0건이면 "대기 없음" 보고 후 종료.
2. status면 목록만 출력 후 종료.
3. 각 항목을 CLAUDE.md의 클러스터 정의대로 형제 파일·재빌드 방법 확인.
4. 마스터 기준 형제 일치(byte-동일 복사), 생성물은 문서화된 빌드 명령으로 재생성,
   파일 내부 "최종 수정" 날짜 갱신.
5. byte-동일·금지어/식별자 0건 검증.
6. 완료 항목을 SYNC-PENDING.md에서 삭제.
7. 무엇을 동기화했는지·남은 대기를 보고.

주의: 실행 검증은 사용자 독립 확인 권유. 커밋 직전이면 비운 뒤 커밋 권유.
