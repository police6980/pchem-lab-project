# 06. 프로젝트 설계 현황 요약

**문서 목적**: 프로젝트의 설계 결정사항과 남은 과제를 한 장에 정리. 새로운 대화 세션에서 빠르게 맥락을 파악하고 이어갈 수 있게 한다.

**최종 업데이트**: 2026년 4월 (MVP 착수 전 최종 설계 확정)

---

## 프로젝트 정체성

**이름**: 지능형 센서-시뮬레이션 통합 과학교육 플랫폼 (AI-Assisted Micro-Macro Interactive Lab)

**핵심 목적**: **"기체 법칙이 성립하는 순간 미시 세계에서 실제로 무엇이 일어나는가를 학생이 볼 수 있게 한다."**

이 플랫폼은 기체 법칙의 **발견 도구가 아니라 이해 도구**다. 학생은 법칙을 교과서로 이미 배웠으나, 그 순간 입자 수준에서 벌어지는 일은 볼 수 없었다. 거시 현상은 실제 실험으로 체험하고(플런저를 누르는 손, 센서에 찍히는 압력), 미시 현상은 시뮬레이션으로 가시화한다(입자 운동, 벽과의 충돌, 속도 분포의 이동). 학생은 두 세계를 동시에 목격하며 Johnstone 삼원 모형의 macro ↔ sub-micro 연결을 경험한다.

**대상 학습자**: 중·고등학교 과학 영재.

**교육학적 근거**: Johnstone의 삼원 모형(macro / sub-micro / symbolic 표상 연결).

**차별화 전략**:
- 센서 구동 물리 시뮬레이션 (vs PhET 같은 가상 구동)
- 실시간 인과 시각화 (공식 결과값이 아닌 물리 과정을 시간축에 표현)
- 충돌 섬광·속도 색상 등 미시 메커니즘의 다층 시각화
- LLM 튜터의 실시간 데이터 기반 개입 (v2 이후)

**주요 선행 연구**:
- Chao, Chiu, DeJaegher, Pan (2016). Sensor-Augmented Virtual Labs. J. Science Education and Technology, 25(1).
- Johnstone, A. H. (1991). Why is science difficult to learn? J. Computer Assisted Learning, 7(2).
- 한국현장과학교육학회 무선 온도 센서 활용 샤를 법칙 실험 개선.

## 프로젝트 범위

### 실험 구성

**기체 법칙 파트 (설계 완료, MVP는 보일만)**:
- 장비 A: 보일 법칙 (압력-부피 관계) — **MVP 대상**
- 장비 B: 샤를 법칙 (온도-부피 관계) — v1.1 대상

**산염기 파트 (설계 예정, v2)**:
- pH 기반 강산/약산 이온화 시각화
- 중화 적정 입자 수준 시뮬레이션
- 온도에 따른 평형 이동 (르샤틀리에)

### 실험별 독립 장비 원칙

공용 장비가 아닌 **실험별 전용 장비**로 제작. 베이스는 검증된 상용 교육 장비를 구매하고 센서만 교체하는 방식.

## 핵심 설계 철학 (최종 확정)

### 두 층의 실험 구성

**시뮬레이션 층 (미시 이해)**: 센서 실측값을 입력받아 미시 세계를 시각화한다. 박스 크기 변화, 입자 밀도, 속도 분포, 충돌 빈도, 타격 세기를 보여준다. 정확한 수치보다 **질적 인과의 시각적 체험**이 목적. 부피 등 계산 파생 수치는 **숫자로 표시하지 않는다** — 시뮬레이션은 정답 제공자가 아니라 해설자다.

**발견 활동 층 (거시 측정)**: 학생이 실제 주사기 눈금을 눈으로 읽어 [기록] 버튼으로 입력한다. 입력 시점의 센서값이 자동 스냅샷으로 함께 저장된다. 5~10개 측정점이 쌓이면 표로 확인하고 PV 곱(보일) 또는 V/T 비(샤를)를 계산해 법칙을 **스스로 확인**한다.

**두 층의 역할 분담**: 학생은 거시 세계에서 **진짜 측정자**가 되고, 미시 세계를 **해설로 이해**한다. 두 활동이 동시에 돌아가며 macro ↔ sub-micro 연결이 완성된다.

### 데이터 처리 원칙

**숫자 계층 (정량)**: 학생이 UI에서 보고 실험 노트에 기록하는 센서값은 **실제 측정값**이다. 가독성을 위한 최소한의 스무딩만 거친다.

**시뮬레이션 계층 (정성)**: 입자 운동, 박스 크기 변화, 히스토그램 이동 등은 센서 변화에 반응해 **미시 인과를 교육적으로 가공**하여 보여준다. 실제 물리 시간과 다를 수 있고, 단위는 **초기 대비 상대값**으로 처리한다.

**출처의 투명성**: 학생이 보는 모든 값에 대해 "센서 실측 / 시뮬 파생 / 학생 입력"의 출처가 UI에서 분명히 드러난다.

### 4대 설계 원칙 (기존 유지)

1. **기성품 우선**: 검증된 상용 실험 장비를 베이스로, 센서만 아두이노 호환 모델로 교체.
2. **센서 최소화**: 한 실험에 1-2개 센서만. 나머지는 계산 또는 수동 입력.
3. **실제 시간 스케일 준수**: 학생 조작으로 즉각 일어나는 변화는 즉시 반영, 열·질량 수송처럼 본래 느린 과정은 지연 수렴으로 시각화.
4. **시각화가 주인공**: 미시 세계 이해가 우선, 측정 정밀도는 부차적.

## 기체 법칙 파트 하드웨어 설계

### 장비 A: 보일 법칙 (MVP 대상)

**베이스 장비**: 상용 기체 법칙 실험 세트 (주사기+압력계+튜브+삼방밸브, 3-5만원)

**핵심 센서**: **DFRobot SEN0257**
- 규격: G1/4 나사, 0~16 bar, 5V 전원, 0.5~4.5V 아날로그 출력
- 특성: 스테인리스 몸체, IP68, 수명 1천만 회
- 교체 방식: 기존 압력계 분리 후 직접 체결 (규격 불일치 시 황동 어댑터 사용)
- 보정: 게이지압 → 절대압 변환 (+101.3 kPa)
- **ESP32 연결 주의**: 출력 0.5~4.5V, ESP32 ADC는 3.3V 한계 → **분압 저항 필수** (10kΩ + 20kΩ 등으로 2/3 스케일링)

**온도**: 보일에서는 온도 센서 **미장착**. 등온 가정. 실험 시작 시 학생이 실온을 입력(예: 298 K)하고 실험 중 불변 가정. 짧은 실험 시간 내 실온 변화는 무시.

**학생 조작**: 주사기 플런저를 손으로 누름. 부피는 눈금을 읽어 [기록] 버튼으로 수동 입력.

**예상 비용**: 8-12만원/세트

### 장비 B: 샤를 법칙 (v1.1 대상)

**베이스 장비**: 유사이언스/창의력쑥!감성과학/칭찬나라큰나라의 "샤를의법칙 실험장치" (에어챔버 기반, 6-10만원)

**핵심 센서**: **DS18B20 방수 프로브**
- 통신: 1-Wire (Arduino 표준 라이브러리 지원)
- 정확도: ±0.5°C, 측정 범위 -55~+125°C
- 교체 방식: 기존 디지털 온도계 분리 후 삽입
- 장착 이슈: 프로브 외경 6mm vs 기존 구멍 3-4mm → 드릴 확장 또는 실리콘 부싱
- 회로: 4.7kΩ 풀업 저항 필수
- 측정 주기: ~1Hz (12비트 변환 시간 ~750ms)

**압력**: 자유 플런저로 기계적으로 일정하게 유지. 센서 없음. UI에 "압력: 일정"으로 표시.

**학생 조작**: 에어챔버를 수조(온수/냉수)에 담금. 부피는 측정부 주사기 눈금을 수동 입력.

**예상 비용**: 10-15만원/세트

### 제어 보드 (확정)

**ESP32** (Uno 아님). 근거:
- 3.3V 로직, 풍부한 ADC, 충분한 성능
- USB 시리얼 그대로 사용 가능
- 나중에 산염기(pH 캘리브레이션 등)·무선 확장 여지
- 가격 차이 미미

## 시뮬레이션 설계 (최종 확정)

### 차원

**2D**. p5.js 최적 사용역, 교육 시뮬 관례, 개발 효율, 교실 환경 적합성, 모든 입자의 완전 가시성. 2D-3D 단위 불일치는 모든 물리량을 "초기 대비 상대값"으로 표시하여 회피. 입자 수는 2D 통계 요동 보상을 위해 **300~400개**.

### 핵심 수렴 원칙

**"센서 측정값은 시뮬레이션의 1차 물리량(속도)에 즉시 반영하고, 2차 물리량(부피)은 물리적 인과 과정을 보여주며 지연 수렴한다."**

- 입자 속도: 센서값 즉시 추종 (tau = 0.05초)
- 박스 부피: 공식 계산값에 지수 수렴 (tau = 0.5초)

### 보일 법칙 시뮬레이션

- 학생 조작: 플런저 누름 → 센서 압력 즉시 증가
- 시뮬 계산: `V = P₀V₀/P` (법칙 가정) → 박스 목표 크기 결정
- 박스가 tau = 0.5s로 부드럽게 좁아짐
- 입자 밀도 증가 → 피스톤 충돌 빈도 증가 (주인공)
- 속도 분포는 거의 불변 (등온)
- 세기는 거의 일정

### 샤를 법칙 시뮬레이션

- 학생 조작: 수조에 담금 → 센서 온도 천천히 변화
- 입자 속도 분포가 T에 즉시 추종 (tau = 0.05s)
- 시뮬 계산: `V = V₀T/T₀` → 박스 목표 크기 결정
- 박스가 tau = 0.5s로 부드럽게 확장
- 속도 히스토그램이 우측으로 이동 (주인공)
- 피스톤 충돌 빈도 소폭 감소, 타격 세기 증가 → 상쇄

### 피스톤-only 충돌 집계

전체 벽이 아니라 **피스톤 면의 충돌만** 카운트. 근거:
1. 실제 센서가 피스톤 위치에 대응
2. 학생 멘탈 모델 일치 ("손에 밀리는 힘")
3. 평형에서 모든 벽이 같은 압력이므로 물리적 등가
4. 피스톤 면적 불변으로 계산 단순
5. 샤를에서 벽 면적 변동 복잡성 제거

### 속도 분포

**맥스웰-볼츠만**. Box-Muller 변환으로 정규분포 난수 생성 → vx, vy 성분에 부여. 초기화 시 v_max_init 기록, 색 매핑과 히스토그램 x축 범위는 `1.5 × v_max_init`로 **고정** (재정규화 안 함, 분포 이동이 시각적으로 드러나도록).

### 시각화 요소

**입자 색상 (HSB 매핑)**:
- Hue: 파랑(240°, 느림) → 빨강(0°, 빠름)
- Saturation: 40% → 100%
- Brightness: 70% → 100%
- 보일: 색 구성 불변, 밀도만 증가
- 샤를: 전체가 파랑→빨강으로 물들며 진해짐

**충돌 섬광**:
- 발생: 입자-피스톤 충돌 순간
- 크기·밝기: 운동량 전달 `2m|v_x|`에 비례
- 색: 해당 입자의 HSB 색
- 지속: 0.1~0.15초 페이드, 시작 alpha ~120
- 보일: 섬광 개수 증가 (밝기 유지)
- 샤를: 섬광 밝기·크기 증가 (개수는 비슷)

**속도 히스토그램**:
- x축 고정 (v_max_color와 동일 스케일)
- 초기 분포를 흐린 참조선으로 남김
- 현재 분포를 선명히
- 막대 색은 속도-색 매핑 공유 (세 시각화가 하나의 색 언어로 통합)

**비색 UI 요소**: 배경, 박스 테두리, 숫자 패널은 무채색. 색은 물리적 의미가 있는 요소에만.

### 튜닝 가능 파라미터 (설정 파일)

| 파라미터 | 기본값 | 의미 |
|---|---|---|
| particle_count | 350 | 화면 입자 수 |
| velocity_tau_seconds | 0.05 | 입자 속도 수렴 시정수 |
| volume_tau_seconds | 0.5 | 박스 부피 수렴 시정수 |
| pressure_smooth_window_sec | 0.3 | 압력 센서 이동평균 |
| temperature_smooth_window_sec | 2.0 | 온도 센서 이동평균 |
| collision_smooth_window_sec | 1.0 | 피스톤 충돌 카운터 스무딩 |
| flash_duration_sec | 0.12 | 충돌 섬광 지속 시간 |
| flash_initial_alpha | 120 | 섬광 시작 투명도 (0-255) |
| v_max_color_factor | 1.5 | 색 매핑 최댓값 배율 (v_max_init 대비) |

## UI 설계 (공통 프레임)

```
┌─────────────────────────────────────────────────┐
│                                                 │
│   [입자 박스 + 섬광]      [속도 히스토그램]         │
│                         (초기 분포 참조선 포함)    │
│                                                 │
│   숫자 패널              기록 패널                │
│                         [기록] 버튼               │
│                         측정점 목록               │
│                         [표 보기] [CSV 저장]      │
└─────────────────────────────────────────────────┘
```

### 숫자 패널 (공통 구조)

```
온도:         [값]        ← 보일: 학생 입력 고정, 샤를: 센서
압력:         [값]        ← 보일: 센서, 샤를: "일정"
─────────
평균 속도:    ×[값]       ← 보일: 1.00 고정, 샤를: 변화
피스톤 충돌:  ×[값]       ← 보일: 증가, 샤를: 소폭 감소
평균 타격세기: ×[값]       ← 보일: 1.00, 샤를: 증가
```

부피는 표시하지 않음. 상대값은 "×1.87" 같은 식.

### 측정점 기록 (자유 클릭 방식)

- 학생이 원하는 순간에 [기록] 버튼 클릭 (자유도 우선)
- V 입력 팝업 → 학생이 주사기 눈금 읽어 입력
- 현재 스무딩된 센서값이 자동 스냅샷
- 목록에 추가, 삭제만 가능 (수정은 v2)
- 안정화 대기 가드 없음 (학생 판단에 맡김)

### 측정점 표

- 누적 측정점 목록
- 자동 계산 열: 보일은 P×V, 샤를은 V/T
- 학생이 "이 값이 거의 일정하네"를 스스로 발견

```json
{"sensor": "pressure", "value": 121.5, "unit": "kPa", "timestamp": 12345}
```

- `\n` 단위 한 줄 한 메시지
- 연결 시 첫 메시지: `{"type": "hello", "device": "boyle_v1"}` (장비 식별)
- 브라우저 → 펌웨어 방향 메시지 없음 (v1)

- 압력: kPa (절대압, 게이지압 + 101.3)
- 온도: 내부 K, 표시 °C 및 K 병기
- 부피: mL (학생 입력)
- 시간: 내부 ms, 표시 s


## 구현 중 발견사항

### v1에서 반데르발스 편차의 부분적 재현 (2026-04)

입자 간 탄성 충돌 구현 후 2단계 검증 중, 고밀도(극단 수축) 상태에서 PV 곱이 기본 상태 대비 약 +16% 상승하는 현상 관찰:

- 저밀도 (50 kPa, width 800): PV = 15,200 (기준)
- 기본 (101 kPa, width 400): PV = 15,200 ✓
- 고밀도 (300 kPa, width 135): PV = 17,685 (+16%)

해석: 입자 반지름(2.5)이 박스 폭 대비 무시 못 할 크기가 되면서 "유효 부피" 감소 효과가 나타남. 이는 반데르발스 방정식 `(P + a/V²)(V - b) = RT`의 b항(입자 크기 보정)의 미시적 재현.

의의: 06 문서에서 "의도적 오차 설계 (반데르발스 편차 시각화)"를 v2로 유보했으나, 탄성 충돌 구현의 부산물로 이미 재현됨. v2 설계 시 이 현상을 교육적으로 활용 가능. 학생이 "왜 극단 상황에서 PV가 이상기체 법칙을 살짝 벗어나는가"를 발견하는 순간이 기체의 실제 성질에 대한 통찰로 이어질 수 있음.

관련 커밋: 5e83191 (탄성 입자 간 충돌 구현)

### v1 구현 과정에서 이론 일치 검증 (2026-04)

시뮬레이션이 교과서 수식과 일치함을 다각도로 확인:

**이상기체 PV = const 검증** (runPVAccuracyTest):
- 슬라이더 81·100·130·160·190·220 kPa 순차 기록
- 편차 **< 0.5%** (기준 2% 여유)
- 조건: 안정화 감지 통과 + 1초 이동평균 적용
- 관련 커밋: 0f575e7 (PV accuracy 개선)

**Charles 법칙 V ∝ T**:
- 0°C (273.15K) → V_baseline 45.8 mL
- 25°C (298.15K) → V_baseline 50.0 mL
- 77°C (350.15K) → V_baseline 58.7 mL
- 선형 관계 정확 (V₀ = 50 × T/298.15)

**Equipartition KE ∝ T**:
- 25°C → 평균 속도 172 px/s, KE 14,796 a.u.
- 77°C → 평균 속도 184 px/s, KE 16,908 a.u.
- KE 비율 16908/14796 = 1.143 ≈ 350.15/298.15 ✓
- 2D 자유도 2개 모두 정확히 thermal

**2D 맥스웰-볼츠만 분포 형태**:
- 이론 곡선 오버레이로 실측과 시각적 일치 확인
- σ = RMS/√2 변환 식 적용 (정확)

관련 커밋:
- c2fae0b (온도 설정 + Charles law)
- 1358ea6 (M-B 시각화, 이론 곡선, 전이 애니메이션)
