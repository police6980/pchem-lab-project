## 실험 개요

**법칙**: 일정 압력에서 기체의 부피는 절대온도에 비례한다. $V/T = k$ (상수).

**학생 조작**: 에어챔버를 수조(온수 또는 냉수)에 담가 기체 온도를 변화시킨다.

**측정 방식**:
- 온도 $T(t)$: 센서로 기체 내부 온도를 실시간 측정
- 부피 $V(t)$: 측정부 주사기 눈금을 학생이 읽어 수동 입력 (v1), 추후 자동화 가능 (v2)
- 압력 $P$: 대기압으로 고정 (측정부 주사기가 자유 플런저라 자동 유지)

**시뮬레이션 연동**: 측정된 온도가 시뮬레이션의 입자 속도와 박스 크기 목표값을 결정. 박스 크기는 지수 수렴으로 천천히 따라가 "빨라진 입자가 벽을 밀어내는 인과"를 시각화.

## 하드웨어 구성

### 베이스 장비 (기성품 구매)

**품목**: 샤를의 법칙 실험 장치 (에어챔버 기반)

**구성 요소**:
- 에어챔버 (금속 또는 유리 재질, 밀폐 설계)
- 디지털 온도계 (챔버 뚜껑에 꽂힌 형태)
- 눈금 실린더 또는 측정부 주사기 (보통 20mL)
- 3-way 콕 (삼방 밸브)
- 연결 튜브

**구매처 후보**:
- **유사이언스** (yooscience.kr): "샤를의법칙 실험장치" 품번 32787
- **창의력쑥!감성과학** (eqscience.co.kr): "샤를의법칙 실험장치" 품번 32579
- **칭찬나라큰나라**: "기체의 법칙 실험기 (보일,샤를의 법칙)" 
- 예상 가격: 6만 ~ 10만원

**제품 설명 (유사이언스)**:
> "air chamber 내부 부피를 알고 온도 변화에 따른 부피 변화를 측정할 수 있다. 외부 열손실을 줄여 실험 오차를 최소화하였다."

**구매 전 확인 사항**:
- 디지털 온도계의 프로브 외경 (보통 3~4mm)
- 챔버 뚜껑의 온도계 삽입 구멍 내경
- 에어챔버 내부 부피 (통상 50~100mL)

### 센서 교체: 온도 센서

**선정 모델**: DS18B20 방수 프로브형

**선정 이유**:
- 1-Wire 통신 (아두이노 표준 라이브러리 지원)
- 방수 스테인리스 프로브 (수조 환경 안정)
- 정확도 ±0.5°C (교육 목적 충분)
- 측정 범위 -55°C ~ +125°C (수조 온도 범위 충분)
- 케이블 일체형 (일반 1m, 필요시 더 긴 것도 있음)
- 국내 수급 용이, 1만 ~ 2만원

**배선**:
- 빨간 선: 5V VCC (또는 3.3V)
- 검은 선: GND
- 노란 선: 데이터 (1-Wire), 4.7kΩ 풀업 저항으로 VCC에 연결 필요

**구매처**: 디바이스마트, 엘레파츠, 쿠팡 등에서 "DS18B20 방수형" 검색

**아두이노 라이브러리**: OneWire, DallasTemperature (Arduino IDE 라이브러리 매니저에서 설치)

### 프로브 장착 (핵심 이슈)

**문제**: DS18B20 방수 프로브의 일반적인 외경은 **6mm**이며, 기성 샤를 장비의 디지털 온도계 구멍은 **3~4mm**인 경우가 많음.

**해결 방법 (우선순위 순)**:

1. **구멍 확장**: 챔버 뚜껑의 구멍을 드릴로 6mm로 확장. 실리콘 또는 에폭시로 실링.
2. **어댑터 부싱 제작**: 실리콘 마개나 고무 패킹에 6mm 구멍을 뚫어 기존 구멍에 끼우는 방식.
3. **3mm 초소형 DS18B20**: 있긴 하지만 가격 3~5만원으로 상승.

**밀폐 유지 필수**: 프로브 장착부의 실링이 불완전하면 기체가 샘. 샤를 법칙이 안 성립함.

### 기타 하드웨어

**제어 보드**: 아두이노 Uno 또는 ESP32 (장비 A와 공용 가능)

**보조 부품**:
- 4.7kΩ 풀업 저항 (DS18B20 필수)
- 수조 (투명 아크릴 또는 비이커, 1L 이상 권장)
- 가열원 (전기포트, 전자레인지 등으로 온수 준비)
- 냉각원 (얼음, 보냉팩)

## 조립 절차

1. 기성 장비 수령 후 디지털 온도계 분리
2. 프로브 구멍 크기 측정 (버니어 캘리퍼스 또는 육안 비교)
3. DS18B20 프로브 삽입
   - 구멍이 작으면 드릴 확장 또는 어댑터 부싱 사용
   - 실링재(실리콘 또는 에폭시)로 구멍 주변 완전 밀봉
4. 프로브 위치 확인: 프로브 끝이 챔버 내부 기체 공간 중앙에 오도록 길이 조정
5. 4.7kΩ 풀업 저항을 DS18B20 데이터 선과 VCC 사이에 연결
6. 아두이노 배선 완료
7. 초기 테스트: 상온에서 약 20~25°C 표시되는지 확인
8. 밀폐 테스트: 챔버를 따뜻한 손으로 감싸쥐면 측정부 플런저가 움직이는지 확인 (움직이면 밀폐 양호)

## 학생 조작 프로토콜

### 초기 상태 설정

1. 에어챔버를 실온(약 20°C)에서 안정화
2. 3-way 콕 개방 → 챔버 내부가 대기압과 평형
3. 측정부 주사기 플런저 위치 기록 (예: 10mL)
4. 3-way 콕 닫음 → 초기 조건 고정: T₀ = 실온, V₀ = 챔버 부피 + 주사기 초기 부피
5. 웹 UI에서 초기값 확인·수정 후 "시작"

### 실험 진행 (가열)

1. 수조에 온수(예: 60°C) 준비
2. 에어챔버를 수조에 담금
3. 온도 센서 값이 상승하기 시작
4. 측정부 주사기 플런저가 기체 팽창에 따라 밖으로 밀려나옴
5. 평형 도달 시(온도 안정) 플런저 최종 위치를 UI에 입력
6. 시뮬레이션이 온도 상승 과정을 실시간 시각화
   - 입자 속도가 거의 즉시 빨라짐
   - 박스 크기가 지수 수렴으로 천천히 증가
   - 학생은 "빨라진 입자가 벽을 밀어내는" 인과를 시각적으로 봄

### 실험 진행 (냉각)

- 얼음물 수조로 옮기고 동일한 과정
- 입자 속도 느려짐 → 박스 수축

### 반복

- 다양한 온도(20°C, 40°C, 60°C, 80°C, 0°C 등)에서 측정
- V-T 그래프 작성 → 선형 관계 확인
- 외삽하면 절대영도 추정 가능 (영재 심화 활동)

## 예상 제작 비용

한 세트당:

- 기성 샤를 실험 장치: 6만 ~ 10만원
- DS18B20 방수 프로브: 1만 ~ 2만원
- 4.7kΩ 저항, 실링재, 전선: 5천원
- 어댑터 부품 (필요 시): 5천 ~ 1만원
- 아두이노 Uno (또는 ESP32): 1만 ~ 3만원
- 수조, 가열기 등 부대 장비: 별도 (학교 과학실 활용)

**합계: 약 10만 ~ 15만원**

## 안전 사항

- 온수 취급 시 화상 주의. 학생에게 "수조 온도 60°C 이하로 제한" 지시 가능.
- 얼음물 취급 시 동상 주의.
- 에어챔버가 유리 재질이면 급격한 온도차에 깨질 위험. 수조 물 온도를 점진적으로 변화시키는 프로토콜 준수.
- 실링 불량으로 기체 누설 시 데이터 왜곡. 실험 전 밀폐 상태 점검.

## 시뮬레이션 연동 특이사항

이 실험은 시뮬레이션의 "실제 시간 스케일 추종" 원칙이 가장 잘 드러나는 케이스다.

- 센서 온도 $T(t)$는 실제 열전달 속도로 변화 (수조 담금 후 수십 초 동안 서서히)
- 시뮬레이션 입자 속도는 $\sqrt{T(t)/T_0}$로 거의 즉시 추종
- 시뮬레이션 박스 크기는 $V_{target} = V_0 \cdot T(t)/T_0$ 로 계산되지만, 실제 표시 부피는 지수 수렴 ($\tau \approx 0.5$초)으로 따라감
- 결과적으로 학생은 "온도 변화 → 입자 빨라짐 → 박스 팽창"의 인과 순서를 시각적으로 인지

세부 물리 규칙은 `04-simulation-physics.md` 참고.

## 확장 가능성 (v2 고려사항)

- 부피 자동 측정: 측정부 주사기 옆에 선형 포텐셔미터 + 자기 커플링. 추가 3~5만원.
- 내부 온도와 수조 온도 동시 측정: DS18B20 추가 1개. 학생이 "온도 지연" 현상을 직접 탐구 가능 (영재 심화).
- 절대영도 외삽 탐구 콘텐츠: 소프트웨어 기능. 다양한 온도 데이터 수집 후 회귀 분석.
