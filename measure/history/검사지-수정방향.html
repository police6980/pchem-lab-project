기체 개념 3-tier 검사지 — 통합 수정 방향

실제 배포 폼(전체 22문항)에 대한 검토 결과 + 기존 보강안 5개 방향 + 신규 아이디어를 하나로 합친 수정 로드맵. 대상은 대학생/예비교사이나 보일·돌턴 개념 특성상 문항 내용은 학교급과 무관(대상 차이로 인한 문항 변경 없음).

관련 문서: 전체 문항 + 정답키 기존 보강안

A 즉시 수정 — 문항 자체 결함

A1. T/F 참·거짓 균형화 (반응 편향 제거)

현재 10개 T/F는 전부 오개념 진술이라 정답이 모두 '거짓'. 응답자가 패턴을 알아채면 내용 이해 없이 전부 '거짓'으로 점수 부풀림(특히 예비교사). 10개 중 4개를 옳은 진술로 전환(정답 '참') + 출제 순서 무작위화. 같은 오개념을 '반대편'에서 측정하므로 진단력은 유지.

코드현재 (오개념·정답 거짓)전환안 (옳은 진술·정답 참)
BL1압력과 부피는 정비례 관계이다압력과 부피는 반비례 관계이다 (정답 참)
BL3밀폐 부피를 줄이면 입자 수가 감소한다밀폐 용기의 부피를 줄여도 입자 수는 변하지 않는다 (정답 참)
DL2전체압 = 부분압들의 평균혼합 기체의 전체압은 각 부분압의 합이다 (정답 참)
DL4무거운 기체가 압력 대부분 차지같은 온도·부피에서 압력은 분자 무게가 아니라 입자 수로 결정된다 (정답 참)
BL2·BL7·PN3·DL1·DL9·MA1그대로 유지 (오개념 진술, 정답 거짓) — 결과: 참 4 / 거짓 6 혼합
대안: 진술 수를 늘려 각 오개념을 '참 버전 + 거짓 버전' 쌍으로 출제(역코딩 신뢰도 점검 가능)하되 문항 수·시간 증가. 위 4개 전환이 시간 영향 0으로 가장 경제적.

A2. Q7 stem 편집 잔여 라벨 제거

Q7 문두 앞 [1단계: 답] 은 작성 중 잔여 표식으로 보임 → 삭제. (다른 문항엔 없음)

A3. Q11 중력 이상화 단서 보강

엄밀히는 중력장에서 기체는 미세한 기압 기울기를 가짐(기압고도식). 화학 전공 예비교사가 "엄밀히는 차이 있음"으로 정답(C)을 비껴갈 수 있음. stem에 "방 정도의 높이차에서는 무시할 수 있다" 단서 추가하여 의도(거시 균일)를 못박음.

B 구조 보강 — 기존 보강안 + 신규

기존 보강안 5개 방향을 실제 폼 상태에 맞춰 재정렬. 폼은 현재 full 22문항·3-tier(확신도 1개)·MC 객관식 이유까지 구현됨.

C 분석 설계 — 문항 추가 없이 즉시 가능

C1. 시뮬 직접효과 vs 전이(통제) 문항 분리

구분문항해석
시뮬 직접효과 문항Q1·Q2·Q3·Q4·Q6·Q7·Q8·Q9·Q10·Q12 + 대응 T/F시뮬이 화면으로 보여주는 개념 → 사후 향상 = 시뮬 효과 직접 증거
통제 소척도 (5문항)Q5(모양)·Q11(중력) + 신설 N1(재질)·N2(시간)·N3(자세)"압력 무관 변수 식별" 단일 구인. 2문항은 척도 불가(α 불안정·이질적) → 5문항으로 확장. 향상 없어야 시뮬 효과 특이성 입증. 개정판에 반영됨.
총점 하나로 묶지 말고 두 하위 점수를 따로 산출. Hake's g·Cohen's d도 '직접효과 문항'에서 계산해야 시뮬 효과가 희석되지 않음.

C2. 이유 선지 오개념 코드북

전체 문항지(검사지-전체문항.html)에서 모든 답·이유 distractor에 오개념 코드를 이미 부여함. 이를 정식 코드북(선지→코드 매핑표)으로 고정하면, 응답 분석 시 "어떤 오개념을 몇 %가 골랐는지" 자동 집계 가능.
