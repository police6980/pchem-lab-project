# 01. 보일 법칙 장비 명세 (장비 A)

**문서 목적**: 보일 법칙 실험 장비의 하드웨어 구성, 센서 사양, 조립 방법, 학생 조작 프로토콜을 정의한다.

---

## 실험 개요

**법칙**: 일정 온도에서 기체의 압력과 부피는 반비례한다. $PV = k$ (상수).

**학생 조작**: 주사기 플런저를 손으로 눌러 기체를 압축한다.

**측정 방식**:
- 압력 $P(t)$: 센서로 실시간 측정
- 부피 $V(t)$: 학생이 주사기 눈금을 읽어 수동 입력
- 온도 $T$: 실온 고정값으로 처리 (측정 불필요)

**시뮬레이션 연동**: 학생이 입력한 부피값이 시뮬레이션 박스 크기를 실시간으로 결정하고, 측정된 압력이 "예측 vs 실측" 패널에 표시된다.

## 하드웨어 구성

### 베이스 장비 (기성품 구매)

**품목**: 기체 법칙 실험 세트 (보일·샤를 법칙용 상용 제품)

**구성 요소**:
- 플라스틱 주사기 (50mL 또는 60mL)
- 압력계 (아날로그, 1~5 bar 범위)
- 연결 튜브
- 삼방 밸브 (3-way stopcock)
- 거치대

**구매처 후보**:
- 과학 교구 업체 (동아사이언스, 사이언스올, 과학상사 등)
- 온라인 쇼핑몰 (11번가, 쿠팡에서 "기체의 법칙 실험기" 검색)
- 예상 가격: 3만~5만원

**구매 전 확인 사항**:
- 압력계 연결부 나사 규격 (가능하면 G1/4 BSP)
- 압력계가 나사 체결식으로 분리 가능한지 여부

### 센서 교체: 압력 센서

**선정 모델**: DFRobot SEN0257 (Gravity Analog Water Pressure Sensor)

**선정 이유**:
- G1/4 나사 규격 (기성 실험 장비의 압력계 자리에 직접 체결 가능)
- 5V DC 전원 (아두이노에서 직접 공급, 별도 어댑터 불필요)
- 0.5~4.5V 아날로그 출력 (아두이노 ADC에 바로 연결)
- 측정 범위 0~16 bar (실험 최대 압력 5 bar의 3배 여유)
- 파손 한계 30 bar (학생 실수에도 안전)
- 스테인리스 몸체, IP68 방수 (교실 환경 내구성)
- 수명 1천만 번 측정
- 아두이노 공식 예제 코드 제공
- 가격: 2만 5천~3만원

**출력 특성**:
- Gauge pressure (게이지압 방식)
- PV=nRT 계산 시 대기압 보정 필요: $P_{abs} = P_{gauge} + P_{atm}$
- 대기압은 101.3 kPa 고정값으로 처리 (교육 실험 수준에서 충분)

**배선**:
- 빨간 선: 5V VCC
- 검은 선: GND
- 노란 선: 아날로그 신호 출력 (아두이노 A0 등)

**구매처**: 디바이스마트, 엘레파츠 (해외 발주, 10~15일 소요), 또는 DFRobot 공식 스토어 직구

**변환 계산 공식**:
```
voltage = analogRead(A0) * (5.0 / 1023.0)
pressure_kPa_gauge = (voltage - 0.5) * (1600.0 / 4.0)  // 0~1600 kPa
pressure_kPa_abs = pressure_kPa_gauge + 101.3
```

※ 오프셋 값(0.5V)은 개별 센서마다 미세 차이가 있을 수 있으므로 초기 캘리브레이션 시 조정.

### 기타 하드웨어

**제어 보드**: 아두이노 Uno 또는 ESP32 (후속 문서에서 확정)

**연결 부품**:
- 기성 장비 압력계 분리 후 SEN0257 직접 체결
- 규격이 맞지 않을 경우 G1/4 변환 어댑터 필요 (황동 피팅, 3천~5천원, 을지로 공구상가 또는 산업용품 쇼핑몰)
- 테프론 테이프로 나사 실링

## 조립 절차

1. 기성 장비 수령 후 압력계 분리 (렌치로 반시계 방향 회전)
2. 드러난 나사산 규격 확인 (G1/4인지 측정)
3. 필요 시 변환 어댑터 준비
4. 나사에 테프론 테이프 2~3회 감기
5. SEN0257 체결, 손으로 조인 후 렌치로 가볍게 마무리
6. 센서 3선을 아두이노에 배선
7. 초기 테스트: 대기압에서 약 0 kPa (gauge) 나오는지 확인

## 학생 조작 프로토콜

### 초기 상태 설정

1. 주사기 플런저를 특정 위치(예: 50mL)에 맞춤
2. 삼방 밸브 개방 (대기압과 평형)
3. 밸브 닫음 → 초기 조건 고정: P₀ = 대기압, V₀ = 50mL, T₀ = 실온
4. 웹 UI에서 "초기 설정" 확인: 센서 측정값을 자동 제안, 학생이 확인·수정 후 "시작" 버튼

### 실험 진행

1. 학생이 플런저를 눌러 부피를 줄임 (예: 40mL)
2. 학생이 UI에 현재 부피 입력 (또는 특정 버튼 클릭)
3. 시뮬레이션 박스가 40/50 = 80%로 축소됨
4. 압력 센서값이 126 kPa 근처로 올라가는 것을 관찰
5. "예측 vs 실측" 패널에서 이상기체 예측값과 비교

### 반복

- 30mL, 25mL, 20mL 등 여러 부피에서 측정
- 각 지점에서 P·V 값 기록 (자동 로그)

## 예상 제작 비용

한 세트당:

- 기성 실험 장비: 3만 ~ 5만원
- DFRobot SEN0257 센서: 2만 5천 ~ 3만원
- 아두이노 Uno (또는 ESP32): 1만 ~ 3만원
- 변환 어댑터, 테프론 테이프, 전선: 5천 ~ 1만원
- USB 케이블, 브레드보드: 5천 ~ 1만원

**합계: 약 8만 ~ 12만원**

학급 규모 세트 구성 시 센서 여분 1~2개 추가 권장 (2만 5천원 × 2 = 5만원 추가).

## 안전 사항

- 주사기 압축 시 플런저 반동 주의. 학생에게 "천천히 누르고 천천히 놓기" 교육.
- 튜브 연결부 이탈 방지: 호스 클램프 또는 강한 실링 적용.
- 센서는 5 bar 이하 범위에서 사용 (정상 작동 한계 20 bar, 파손 한계 30 bar이지만 교실 환경은 10 bar 이내 유지 권장).

## 확장 가능성 (v2 고려사항)

- 부피 자동 측정: 선형 포텐셔미터 + 플런저 링크 막대 구조 추가 가능. 추가 비용 3~5만원.
- 대기압 자동 측정: BMP280 보조 센서 추가. 정확도 향상. 추가 5천원.
- 반데르발스 편차 시각화: 시뮬레이션 소프트웨어 쪽 개선 사항. 하드웨어 변경 없음.
