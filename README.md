# 지능형 센서-시뮬레이션 통합 과학교육 플랫폼

**AI-Assisted Micro-Macro Interactive Lab**

학생이 실제 실험(거시적 관찰)을 수행하는 동안, 해당 실험 데이터와 실시간으로 연동되는 입자 수준의 시뮬레이션(미시적 모델)을 제공하고, 생성형 AI가 튜터로서 개입하여 학생의 인지적 성장을 돕는 지능형 탐구 플랫폼.

## 프로젝트 개요

단순한 현상 관찰을 넘어, 데이터의 이면을 분석하고 추론하는 고차원적 과학 탐구 환경을 제공한다. 대상은 과학 영재 학생이며, 중학교·고등학교 교육과정의 기체 법칙과 산염기 개념을 핵심 소재로 한다.

## 시스템 아키텍처

- **하드웨어**: 아두이노(ESP32 등) + 화학 센서(pH, 온도, 압력 등)
- **소프트웨어**: PC 웹 브라우저 기반 시뮬레이션 (p5.js, Web Serial API)
- **AI 엔진**: 생성형 LLM API를 통한 실시간 데이터 분석과 튜터링

## 폴더 구조

- `docs/`: 설계 문서 모음. 모든 판단과 결정의 기록.
- `firmware/`: 아두이노/ESP32 펌웨어 코드.
- `web/`: 웹 기반 시뮬레이션과 UI 코드.
- `data-logs/`: 실험 데이터 로그 파일 (로컬 전용, Git 제외).

## 개발 환경

- Node.js (웹 앱 개발용)
- Arduino IDE 또는 PlatformIO (펌웨어 개발용)
- Chrome/Edge 브라우저 (Web Serial API 필요)

## 로컬 개발 실행 방법

실물 ESP32가 없어도 Mock 센서로 웹 앱 전체를 구동할 수 있다.

1. PowerShell에서 프로젝트의 `web/` 폴더로 이동:
   ```powershell
   cd web
   python -m http.server 8000
   ```
2. 브라우저(Chrome/Edge)에서 `http://localhost:8000` 접속.
3. 개발자 도구(F12) → **Console** 탭을 열어 센서 JSON 메시지가 20Hz로 찍히는지 확인.
   ```
   { sensor: "pressure", value: 101.32, unit: "kPa", timestamp: 1234.5 }
   ```
4. 화면 좌상단의 `[DEV MODE] 압력:` 슬라이더를 움직이면 Console에 찍히는 값이 즉시 따라오는지 확인.

센서 소스는 `web/js/main.js`의 `USE_MOCK_SENSOR` 플래그로 전환된다. 실물 ESP32 연결 단계가 되면 이 플래그를 `false`로 바꾸고 실제 Web Serial 소스를 붙인다.

## 실험 구성

### 기체 법칙 실험
- **보일 법칙 (장비 A)**: 주사기 기반 압력-부피 관계 탐구
- **샤를 법칙 (장비 B)**: 에어챔버 기반 온도-부피 관계 탐구

### 산염기 실험 (설계 예정)
- pH 센서 기반 강산/약산 이온화 시각화
- 중화 적정 시뮬레이션
- 온도에 따른 평형 이동 탐구
