**문서 목적**: 시뮬레이션이 통계역학 이론과 일치하는지 검증한 기록. 수업 투입·논문 발표·공동연구자 검토 시 근거 자료로 사용한다.

**마지막 업데이트**: 2026-04-26 (Phase 5.3 완료 — 돌턴 입자간 충돌 정량 검증 § 9 추가).
**검증 단계**: Phase 1 MVP 완료 시점

## 1. 왜 검증이 필요한가

교육용 시뮬레이션이라도 **물리적으로 잘못된 것을 가르치면 안 된다**. 영재 교육 맥락에서는 학생이 나중에 고급 통계역학·열역학을 배울 때 **모순을 만나지 않도록** 시뮬레이션이 이론적으로 정확해야 한다.

검증의 세 층위:
1. **거시 법칙**: 보일·샤를 등이 시뮬 내에서 성립하는가
2. **미시 분포**: 입자 속도 분포가 맥스웰-볼츠만과 일치하는가
3. **내부 일관성**: 온도 변경·압력 변경이 예상 비율로 변화하는가

## 3. 보일 법칙 검증

### 3.1 설계 원리

시뮬레이션은 이상기체를 **기하학적으로 강제**한다:
- 슬라이더 압력 `P` → `target_width = P₀·V₀ / P` 계산
- 박스 폭이 target으로 지수 수렴 (`volume_tau = 0.5 s`)
- 즉 `P·V = P₀·V₀` 가 구조적으로 강제됨

### 3.2 초기 편차 발견과 수정 (개발 과정)

최초 측정에서 P·V 편차 **±10 %** 발견 (기대 2 %를 훨씬 초과).

**원인 분석** (두 가지 복합):

1. **Cap 편향** (약 −6.5 %): 슬라이더 하한 74.8 kPa에서 `target_width`가 `BOX_MAX_WIDTH` (760 px)에 걸려 박스가 더 커질 수 없음 → 실제 V가 이론치보다 작게 측정됨.
2. **Transient 편향** (약 ±10 %): 슬라이더 조작 직후 `smoothedP` (τ ≈ 475 ms)와 `box.width` (τ ≈ 500 ms)이 수렴 중인 상태에서 기록 → 위상 불일치로 P·V 요동.

**해결책**:
1. 슬라이더 하한을 70 → **81 kPa**로 상향 (cap 회피)
2. 안정화 감지 도입: 1 s 윈도우, 0.5 % 상대변화 임계
3. 기록 시 즉시값 대신 **최근 1 s 이동평균** 저장
4. `[기록]` 버튼 안정화 전 비활성 + "값 안정화 중…" 힌트 표시

관련 커밋: `0f575e7` (PV accuracy 개선).

### 3.3 수정 후 수동 측정 결과

6 개 측정점 (수동 슬라이더 조작, 각 점에서 안정화 대기 후 기록):

### 3.4 자동 회귀 테스트 (`runPVAccuracyTest`)

## 4. 속도 분포 (맥스웰-볼츠만) 검증

### 4.1 이론 예측

2D 이상기체의 속도 분포는 맥스웰-볼츠만:

```
f(v) ∝ v · exp(−m·v² / (2 k T))
```

주요 관계:
- 평균 속력 `⟨|v|⟩ ∝ √T`
- 평균 운동에너지 `⟨KE⟩ ∝ T` (equipartition, 2D는 자유도 2)
- 분포 봉우리(최빈 속력) 위치 `∝ √T`

### 4.2 실측 (0 °C ↔ 77 °C 비교)

온도만 변경하고 다른 조건은 모두 동일하게 유지한 측정.

| 지표 | 0 °C (273.15 K) | 77 °C (350.15 K) | 비율 |
|---|---|---|---|
| 평균 속도 (px/s) | 153 | 174 | **1.137** |
| 평균 운동에너지 (a.u.) | 11 747 | 15 059 | **1.282** |

**이론 예측 비율**:
- 속도: `√(350.15 / 273.15) = 1.132`
- KE: `350.15 / 273.15 = 1.282`

**실측과 이론 일치**:
- 속도: 1.137 vs 1.132 → 오차 **0.4 %**
- KE: 1.282 vs 1.282 → 오차 **0.0 %**

2D 자유도(x, y) 두 축 모두 정확히 열적 평형 상태임이 확인됨.

### 4.3 히스토그램 시각 검증

이론 곡선 오버레이 기능(`renderer.js`)으로 분포 형태 검증:
- 25 °C 에서 히스토그램 봉우리 위치와 이론 곡선 peak 위치 일치
- 분포 꼬리(고속 영역)의 지수 감쇠 모양도 시각적으로 일치
- σ = v_RMS / √2 변환식 적용 (2D 맥스웰-볼츠만의 표준 변환)

## 5. 입자 간 상호작용

### 5.1 탄성 충돌 구현

O(N²) 법선 임펄스 교환 방식 (`simulation.js`):
- 두 입자 중심 거리 < 반지름 합 → 충돌 감지
- 법선 방향 운동량만 교환, 접선 방향은 보존
- 에너지 완전 보존 (탄성)

관련 커밋: `5e83191` (입자 간 탄성 충돌 구현).

### 5.2 반데르발스 편차 유사 현상 — 설계적 기반

실제 기체의 반데르발스 편차는 입자 부피(b 항)와 인력(a 항)에서 비롯된다. 시뮬의 탄성 충돌 구현은 **b 항 효과의 기하학적 기반**을 제공한다:
- 고압·소부피 영역에서 입자 중심 간 평균 거리 감소
- 입자 반지름이 박스 폭 대비 무시할 수 없게 되면 "유효 부피" 감소

**현재 Phase 1 MVP 에서는 이 편차가 직접 관찰되지 않는다**. 이유는 박스 폭이 `P₀V₀/P` 공식으로 강제되기 때문에 이상기체 법칙이 우선 성립하며, 입자 간 상호작용은 분포 형태에만 반영되고 거시 P·V 값에는 영향을 주지 않도록 설계됨.

**Phase 4 활용 계획**: 실센서 도입(Phase 3) 후 실측 데이터와 시뮬의 비교 모드에서 "이상기체 vs 실제 기체" 편차를 시각적 비유로 설명할 때 이 기반이 사용될 수 있다.

## 6. 온도 변경의 내부 일관성

### 6.1 속도 스케일링 정확성

온도 변경 시 모든 입자 속도에 `√(T_new / T_old)` 곱 (`system.scaleVelocities`). 0.3 s 시정수(`TRANSITION_TAU`)로 부드러운 보간.

**검증**: 25 °C → 50 °C → 25 °C 왕복 후 원래 평균 속도로 복원됨. 누적 드리프트 없음.

### 6.2 V_baseline 샤를 법칙 연동

온도 T 에서의 기준 부피 (`main.js` `recomputeV0Current`):

```
V_baseline(T) = 50 mL × (T / 298.15 K)
```

| 온도 | V_baseline (mL) |
|---|---|
| 0 °C (273.15 K) | 45.80 |
| 25 °C (298.15 K) | 50.00 |
| 50 °C (323.15 K) | 54.19 |
| 77 °C (350.15 K) | 58.72 |

`V / T = const` 자동 성립. 샤를 법칙 내재.

### 6.3 PV = nRT 일관성

각 온도에서 측정한 평균 P·V:

| 온도 | 측정 평균 P·V | 이론 예측 | 일치 |
|---|---|---|---|
| 25 °C | ≈ 5 066 | 101.3 × 50 = 5 065 | ✓ |
| 50 °C | ≈ 5 490 | 5 066 × 323.15/298.15 = 5 490 | ✓ |
| 77 °C | 예상 5 946 | 5 066 × 350.15/298.15 = 5 949 | 재검증 필요 |

`PV / T` 가 온도에 무관하게 일정 → 이상기체 법칙 `PV = nRT` 성립.

## 7. 안정화 감지 정확성

### 7.1 설계

- 최근 20 샘플(50 ms × 20 = 1 s) 동안의 `smoothedP`, `box.width` 버퍼 추적
- 두 값 모두 상대 변화 < **0.5 %** 일 때 `isStabilized = true`
- 슬라이더 `input` 이벤트 시 버퍼 즉시 비움 → `false` 리셋

### 7.2 타이밍 실측

- 슬라이더 정지 후 안정화 판정까지 **평균 1.2~1.5 s**
- 이 대기로 P·V 편차가 ±10 % → **±0.5 %** 로 감소

### 7.3 엣지 케이스

- 슬라이더를 연속 조작하면 매번 리셋 (정상)
- 안정화 직전에 슬라이더 재조작 → 다시 "안정화 중" 진입 (정상)
- 빠른 연속 클릭으로 UI 꼬임 발생하지 않음 (`[기록]` 버튼 disabled 상태 반영)

## 8. 한계와 주의사항

### 8.1 현재 검증의 한계

- **Mock 센서만 검증됨** — 실 ESP32 센서와의 일치는 Phase 3에서
- **학생 실제 실험 패턴에서의 정확도 미확인** — 교실 환경 검증은 Phase 3+
- **장시간 실행(>10 분) 드리프트 미검증**
- **극한 조건 (>300 kPa 또는 <0 °C) 미검증** — 슬라이더 범위와 온도 UI 범위 내에서만 검증

### 8.2 2D vs 3D 차원 차이

본 시뮬레이션은 **2D**. 실제 기체는 3D.
- 2D equipartition: `⟨KE⟩ = kT` (자유도 2)
- 3D equipartition: `⟨KE⟩ = (3/2) kT` (자유도 3)

교육적으로는 2D가 더 직관적 (모든 입자가 보임). 정량 비교 시 이 차이를 인지해야 하며, "단위 보정" 없이 2D 결과를 3D 실기체와 직접 비교하지 않도록 주의.

### 8.3 이상기체 강제의 교육적 이중성

**장점**: 보일 법칙이 완벽히 성립 → 학생이 법칙 자체를 명확히 학습
**단점**: 실제 기체의 편차 관찰 불가 → Phase 4에서 실센서로 보완

이 균형은 **설계 선택**이다. MVP 단계에서는 "이상 법칙 학습"을 먼저 확립하고, 이후 "실제 기체의 이탈"을 별도 단계에서 탐구하는 순서가 교육학적으로 유리하다고 판단.

## 9. 돌턴 입자간 충돌 정량 검증 (Phase 5.3, 2026-04-26)

Phase 5.3 에서 돌턴 페이지에 입자간 탄성 충돌 (직접 구현) 도입. `simulation.js` 의 `_resolveParticleCollisions` (보일/입자운동) 와 별개로 돌턴 전용 `resolveCollision` (1D 탄성 충돌 + 위치 분리 W4-simple, spatial hash O(N), 가스별 질량 `M`) 추가.

### 9.1 검증 환경

- **파일**: `tests/dalton-collision-test.js` (Node.js 단독 실행, main.js 의 충돌 함수 자립형 복사)
- **결과**: `tests/dalton-collision-test-result.txt` (보존)
- **시뮬 환경**: He 50 + CO₂ 50, 박스 1000×1000, dt=0.005, step=10000
- **입자 속도**: Box-Muller 정규분포 × `speedFactor` (Graham 법칙: 1/√M, 공기=29 기준 정규화)

### 9.2 7 검증 항목 + 결과 (5/7 PASS)

| # | 검증 | 결과 | 수치 |
|---|---|---|---|
| 1 | KE 보존 (오차 < 0.5%) | **PASS** | 오차 0.0000% |
| 2 | 운동량 (벽 반사 영향 정상) | **PASS** | 변화량 합리 범위 |
| 3 | Equipartition (`<KE_He> ≈ <KE_CO₂>`) | FAIL (평형 미도달) | 비율 0.74 (기대 1.0) |
| 4 | `<\|v\|_He> / <\|v\|_CO₂> ≈ √(M_CO₂/M_He) = √11 ≈ 3.32` | FAIL (평형 미도달) | 비율 2.85 (오차 14%) |
| 5 | M-B 분포 (피크 + 꼬리) | **PASS** (시각) | 히스토그램 비대칭 확인 |
| 6 | 입자 겹침 (10000 검사) | **PASS** | 0 회 |
| 7 | KE 안정성 (CV) | **PASS** | CV 0.0000% |

### 9.3 검증 3, 4 FAIL 원인 분석

- **알고리즘 자체 정확** — 검증 1, 6, 7 PASS (KE 완전 보존, 겹침 0, CV 0%)
- **1D 탄성 충돌 식 검증**: `v1'·n = v1·n × (m1-m2)/(m1+m2) + v2·n × 2m2/(m1+m2)` — 표준식 일치
- **FAIL 원인**: 평형 미도달 (충돌 횟수 부족)
  - 박스 1000×1000 × 입자 100 = 충진율 0.3% (낮음, 평균 자유 거리 큼)
  - step=10000 × dt=0.005 = 50초 → 입자당 평균 ~8 충돌 (평형 도달에 부족, 보통 수백 충돌 필요)
- **수정 방향** (후속): 박스 200~300 + step 30000~100000 으로 평형 도달 가능

### 9.4 학습 정합

- **Graham 법칙 (1/√M) 정확 적용 ✓**:
  - 정의 (`web/config/params.json` dalton.gases): air 1.00, CO₂ 0.81 (= √(29/44)), He 2.69 (= √(29/4)), N₂ 1.02, O₂ 0.95 — 학술적으로 정확 (소수 둘째자리 반올림)
- **NVE ensemble (KE 보존) ✓**: 시뮬 등온 평형 자연 거동
- **R1 + R5 만 적용**: R2/R3/R4 텔레포트 모드라 입자 부재 — 충돌 처리 불필요
- **simulation.js 무영향**: 돌턴 한정 `M` 속성, `resolveCollision` 함수 — 보일/입자운동 무영향

### 9.5 라이브러리 도입 검토 (Matter.js)

직접 구현 시 spatial hash / 1D 탄성 충돌 / 위치 분리 W4-simple / 끼임 정정 v1~v5 (~3시간 누적 손실) 등 라이브러리 영역 코드를 점진 직접 작성. **별 브랜치 (`experiment/matter-js`) 에서 추후 시도 의향** — 직접 구현 ↔ 라이브러리 비교 자료가 논문 강력한 1차 자료가 될 수 있음. 상세는 `docs/10-dev-journal.md` § Phase 5.3 의 결정 "입자간 탄성 충돌 — 직접 구현 (라이브러리 도입 보류)".

## 9. 재현 가능성

### 9.1 속도·KE 비율 재현

1. 페이지 로드 후 1~2 s 대기 (초기 분포 안정화)
2. 온도 `0 °C` 프리셋 클릭 → 전이 완료 대기 (~1.5 s)
3. 숫자 패널의 **평균 속도**·**평균 운동에너지** 기록
4. 온도 `77 °C` 프리셋 클릭 → 전이 완료 대기
5. 숫자 패널 값 기록
6. 비율 계산 → 이론값과 비교
   - 속도 비: `√(350.15/273.15) = 1.132`
   - KE 비: `350.15/273.15 = 1.282`
