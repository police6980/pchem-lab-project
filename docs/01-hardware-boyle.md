# 01. 보일 법칙 장비 명세 (장비 A)

**문서 목적**: 보일 법칙 실험 장비의 하드웨어 구성, 센서 사양, 조립 방법, 학생 조작 프로토콜을 정의한다.

## 실험 개요

**법칙**: 일정 온도에서 기체의 압력과 부피는 반비례한다. $PV = k$ (상수).

**학생 조작**: 주사기 플런저를 손으로 눌러 기체를 압축한다.

**측정 방식**:
- 압력 $P(t)$: 센서로 실시간 측정
- 부피 $V(t)$: 학생이 주사기 눈금을 읽어 **수동 입력** (실센서 모드 원칙 — 센서로 역산한 예측값을 그대로 기록하면 $PV=k$ 가 동어반복으로 성립해 검증 의미 소실. 관련 결정: dev-journal 2026-04-23)
- 온도 $T$: 실온 고정값으로 처리 (측정 불필요)

**시뮬레이션 연동**: 센서가 측정한 압력이 시뮬레이션 박스 폭을 이상기체 방정식대로 움직여 미시·거시 대응을 시각화한다. 학생이 입력한 부피는 측정 기록(CSV) 및 $PV$ 검증 계산의 실제 출처.

## 하드웨어 구성

### 압력 센서: DFRobot Gravity 1.6MPa

| 항목 | 값 |
|---|---|
| 모델명 | DFRobot Gravity Analog Water Pressure Sensor (1.6 MPa) |
| 측정 범위 | 0 ~ 1,600,000 Pa (0 ~ 1.6 MPa, 0 ~ 16 bar) |
| 출력 | 아날로그 0.5 V (0 Pa) ~ 4.5 V (1.6 MPa), 선형 |
| 전원 | DC 5 V |
| 나사 규격 | G1/4 BSP 수나사 |
| 몸체 | 스테인리스, IP68 방수 |
| 응답 시간 | < 2 ms |
| 구매처 | 네이버 스마트스토어(프라임무역63 등), 디바이스마트, DFRobot 공식 |
| 가격 | 36,130 원 (국내 유통, 무료배송 기준) |

**선정 이유**:
- G1/4 나사 규격 → 루어락→G1/4 변환 어댑터로 주사기와 체결 가능
- 0.5~4.5 V 선형 출력 → ESP32 ADC(12 bit, 0~3.3 V)로 전압 분배기 거쳐 직접 수신
- 측정 범위 16 bar → 학생이 손으로 낼 수 있는 최대 압력(~4 bar)의 4배 여유, 파손 위험 거의 없음
- 게이지압 출력: $P_\text{abs} = P_\text{gauge} + P_\text{atm}$. 대기압 101.3 kPa 고정값으로 보정 (교육 실험 수준 충분)

### 제어 보드: ESP32 DevKit C v4

| 항목 | 값 |
|---|---|
| MCU | ESP32 (Xtensa LX6 듀얼코어) |
| ADC 해상도 | 12 bit (0 ~ 4095) |
| ADC 입력 범위 | 0 ~ 3.3 V |
| 센서 연결 핀 | GPIO34 (ADC1_CH6, 입력 전용) |
| 전원 | USB-C 또는 Micro-USB 5 V |
| 통신 | USB-CDC 시리얼 (115200 baud) |

ESP32를 Uno 대신 선택한 근거: Wokwi 시뮬레이터 공식 지원 + 12 bit ADC(Uno는 10 bit) + USB-CDC 네이티브. 펌웨어 세부는 `firmware/boyle/boyle.ino`.

### 전압 분배 회로

센서 최대 출력 4.5 V 를 ESP32 ADC 안전 범위(3.3 V)로 낮추기 위해 2 저항 분배기 필요.

```
센서 SIG (0.5 ~ 4.5 V) ─┬─ R1 (10 kΩ) ─┬─ ESP32 GPIO34 (0 ~ 3.3 V)
                        │              │
                        │              └─ R2 (27 kΩ) ── GND
```

- 분배비: $R_2 / (R_1 + R_2) = 27 / 37 \approx \mathbf{0.7297}$
- 센서 최대 4.5 V × 0.7297 ≈ **3.28 V** (ESP32 상한 3.3 V 이내, 안전 여유 0.02 V)
- 펌웨어가 이 비율로 역산해 원래 센서 전압 복원

**저항 조건**: 1/4 W 이상, **±1 % 정밀도 권장**. ±5 % 일반 저항도 동작하나 개별 보정 절차 필요. 국내 유통 금속피막 저항으로 충분.

### 배선도

```
┌── DFRobot Gravity 1.6 MPa ──┐         ┌── ESP32 DevKit C v4 ──┐
│                             │         │                       │
│   빨강 (VCC) ───────────────┼────────>│ 5V (또는 VIN)         │
│   검정 (GND) ───────────────┼────┬───>│ GND                   │
│   노랑 (SIG) ──┐            │    │    │                       │
│                │            │    │    │                       │
└────────────────┼────────────┘    │    │                       │
                 │                 │    │                       │
                R1 (10 kΩ)         │    │                       │
                 │                 │    │                       │
                 ├──────────────────────>│ GPIO34 (ADC1_CH6)    │
                 │                 │    │                       │
                R2 (27 kΩ)         │    │                       │
                 │                 │    │                       │
                 └─────────────────┘    └───────────────────────┘
                       GND
```

**배선 주의**:
- 센서 VCC 는 반드시 ESP32 **5 V (또는 VIN)** 핀. `3V3` 에 연결하면 센서 미동작 (정격 5 V).
- GND 는 센서·R2·ESP32 세 지점 모두 공통 접지.
- 브레드보드로 임시 시험 가능. 수업 배포용은 만능기판 납땜 권장 (점퍼 빠짐으로 인한 스파이크 방지).
- USB 케이블은 **데이터 전송 가능** 종류. 충전 전용 케이블은 시리얼 통신 불가.

### 변환 공식 (펌웨어 `readPressurePa()` 내장)

```
raw     = analogRead(34)                         // 0 ~ 4095
vAdc    = raw × 3.3 / 4095                       // ESP32 ADC 입력 전압 (V)
vSensor = vAdc / 0.7297                          // 전압 분배기 역산 → 센서 원래 전압 (V)
P_Pa    = (vSensor − 0.5) / 4.0 × 1,600,000      // 선형 매핑 → Pa (0 ~ 1.6 MPa)
P_Pa    = clamp(P_Pa, 0, 1_600_000)              // 상하한 클램프
```

브라우저 측 공통 파서(`web/js/protocol.js`)가 이 Pa 정수를 `p/1000` 으로 kPa 환산해 UI·시뮬·AI 튜터 컨텍스트에 전달. 상세: `firmware/boyle/boyle.ino`, `docs/05-data-format.md` v1.1.

개별 센서 오프셋(0.5 V)은 공장 보정되어 있으나 미세 편차 가능. 웹 UI [🎯 영점 캘리브] 버튼으로 현재 대기압을 $p_0$ 로 저장하고 상대 측정으로 전환할 수 있다(실센서/에뮬레이터 모두 지원).

### 기타 조립 부품

| 부품 | 사양 |
|---|---|
| 주사기 | 50 mL 또는 60 mL, 루어락 팁 (플라스틱, 의료용) |
| 실리콘 튜브 | 내경 3~5 mm, 길이 20 cm 내외 |
| 삼방 밸브 (3-way stopcock) | 루어락 규격 (의료용) |
| 루어락 → G1/4 변환 어댑터 | 황동 또는 스테인리스 (알리익스프레스·국내 산업용품) |
| 저항 | R1 = 10 kΩ, R2 = 27 kΩ, 1/4 W, ±1 % |
| 브레드보드 + 점퍼 | 시험용. 최종판은 만능기판 납땜 |
| USB 케이블 | 데이터 전송용 (ESP32 포트에 맞는 USB-C 또는 Micro-USB) |

## 조립 절차

1. 주사기(50 mL) 팁에 루어락→G1/4 변환 어댑터 체결. 나사산에 **테프론 테이프 2~3 회** 감아 기밀성 확보.
2. 어댑터 타측에 DFRobot Gravity 1.6MPa 센서 G1/4 수나사를 돌려 체결. 렌치로 가볍게 마무리.
3. (선택) 주사기와 센서 사이 삼방 밸브 삽입 — 대기압 개방·폐쇄 전환 용이. 배관: 주사기 팁 → 삼방 밸브 → 센서.
4. 센서 3선(빨강·검정·노랑)을 브레드보드에서 분배기와 결선 (위 배선도).
5. ESP32 를 USB 로 PC에 연결, `firmware/boyle/boyle.ino` 플래시 (Arduino IDE).
6. 초기 테스트: 삼방 밸브 개방 상태에서 브라우저 WS/실센서 모드 연결 → $p \approx 101{,}325 \pm 500$ Pa (대기압) 확인. 오차 크면 [영점 캘리브] 실행.
7. 밸브 닫고 플런저를 밀어 압축 → 센서 값 상승 확인, 놓으면 원상 복귀.

Wokwi 에서 펌웨어 로직은 실물 없이 검증됨 (포텐셔미터로 ADC 0~3.3 V 흉내). 상세: `firmware/README.md`.

## 학생 조작 프로토콜

### 초기 상태 설정

1. 주사기 플런저를 특정 위치(예: 50 mL)에 맞춤
2. 삼방 밸브 개방 → 내부 기체 대기압과 평형
3. 밸브 닫음 → 초기 조건 고정: $P_0 \approx 101.3$ kPa, $V_0 = 50$ mL, $T_0 = $ 실온
4. 웹 UI에서 [🎯 영점 캘리브] 1회 실행 권장 (센서 오프셋 흡수)

### 실험 진행

1. 플런저를 눌러 기체 압축 (예: 40 mL)
2. 주사기 눈금을 **직접 읽어** 웹 UI `V` 입력 필드에 타이핑 (예: `40`)
3. 압력 센서값이 상승 → UI에 `P ≈ 126 kPa` 근처로 표시
4. [기록] 버튼 클릭 — 첫 측정이거나 직전 $V$ 와 같으면 확인 경고 (시린지 눈금과 입력값 일치 재확인)
5. 시뮬레이션 박스가 압력 변화에 따라 축소 → 입자 밀도 증가·충돌 빈도 증가를 관측

### 반복

- 30 mL / 25 mL / 20 mL 등 여러 부피에서 측정
- 각 지점에서 $P \cdot V$ 값 자동 계산·기록, 3 점 이상부터 분석 화면 노출
- 산점도(PV)·역수 플롯(1/V vs P)·이상곡선 비교 제공

### 보고서 생성

측정 2~5 점 + AI 튜터 대화 후 [보고서 생성] → docx 파일 자동 작성. 데이터 소스(실센서/에뮬레이터/시뮬)에 따라 AI 질문·서술 맥락이 달라짐.

## 안전 사항

- 주사기 압축 시 플런저 반동 주의. 학생에게 "천천히 누르고 천천히 놓기" 교육.
- 튜브 연결부 이탈 방지: 호스 클램프 또는 강한 실링(테프론 테이프) 적용.
- 학생이 낼 수 있는 최대 압력은 400 kPa 수준. 센서 정격 16 bar(1.6 MPa)의 1/4 이하라 물리적 위험 낮음.
- USB 전원만 사용. 외부 5 V 어댑터 금지 (GND 공통 실수 방지).

## 확장 가능성 (후속 Phase 고려)

- **부피 자동 측정**: 선형 포텐셔미터 + 플런저 링크 막대 구조. V 수동 입력 제거 가능. 추가 비용 3~5 만원. 단 학생의 "눈금 읽기" 교육 가치 상실 — 교육 목적에 따라 결정.
- **대기압 자동 측정**: BMP280 보조 센서(I²C) 추가. 게이지→절대압 보정 자동화. 추가 5 천원.
- **반데르발스 편차 시각화**: 시뮬레이션 소프트웨어 개선 (하드웨어 무변경). 고밀도 조건에서 이상기체 대비 편차를 명시적으로 표시.
- **샤를 법칙 연계 장비(장비 B)**: 에어 챔버 + DS18B20 온도 센서. `docs/02-hardware-charles.md` 참조.
