# 12. 프로토콜 v1.2 — 멀티채널 확장 명세

**문서 목적**: v1.1 단일 채널 프로토콜을 멀티센서(돌턴 2채널 등)로 확장하는 wire format 명세.

**마지막 업데이트**: 2026-04-27 (Phase 5.4 Step I-pre-1).

**변경 원칙**:
- v1.1 하위 호환 유지 — `ch` 필드 없는 메시지는 `ch: 0` (기본 채널) 으로 해석
- 에뮬레이터·실 펌웨어 동일 스키마
- 파서(`protocol.js`) 단일 코드 경로, 실험별 분기 없음

---

## v1.1 → v1.2 변경 요약

| 항목 | v1.1 | v1.2 |
|------|------|------|
| 데이터 프레임 채널 | 암묵적 단일 | `ch` 필드 (정수, 0-based) |
| hello 메시지 | 단일 센서 라벨 | `channels` 배열로 센서 목록 전달 |
| calib 요청/ACK | 전체 일괄 | `ch` 지정 → 채널별 독립 캘리브 |
| cfg 주기 설정 | 전체 일괄 | 변경 없음 (전체 적용 유지) |
| 버전 협상 | `"t":"s"` 존재 → v1.1 | `"t":"s"` + `channels` 배열 존재 → v1.2, 없으면 v1.1 폴백 |

## 펌웨어 → 브라우저

### (1) `"t":"d"` — 데이터 프레임

```json
{"t":"d","ch":0,"p":101325,"T":25.0,"ts":12345}
{"t":"d","ch":1,"p":203400,"T":25.1,"ts":12345}
```

| 필드 | 타입 | 필수 | 설명 |
|------|------|------|------|
| `t` | string | Y | `"d"` 고정 |
| `ch` | integer | N | 채널 인덱스 (0-based). 생략 시 `0`. |
| `p` | integer | Y | 압력 (Pa 정수) |
| `T` | number | Y | 온도 (°C float) |
| `ts` | integer | Y | 펌웨어 부팅 이후 경과 ms |

**채널 할당 규약** (돌턴 실험):

| ch | 물리 위치 | 센서 | 용도 |
|----|----------|------|------|
| 0 | 주사기 B (수용측) | DFRobot SEN0257 #1 | P_total 측정 (주입 후 총압) |
| 1 | 주사기 A (능동측) | DFRobot SEN0257 #2 | P_A 모니터링 (주입 전 초기압) |

보일 실험은 `ch: 0` 단일 채널만 사용 → 기존 동작 유지.

### (2) `"t":"s"` — hello

```json
{
  "t": "s",
  "sensor": "DFRobot-1.6MPa",
  "fw": "1.2.0-emulator",
  "channels": [
    {"ch": 0, "sensor": "DFRobot-1.6MPa", "label": "B-receiver"},
    {"ch": 1, "sensor": "DFRobot-1.6MPa", "label": "A-injector"}
  ]
}
```

| 필드 | 타입 | 필수 | 설명 |
|------|------|------|------|
| `sensor` | string | Y | 대표 센서 모델 (v1.1 호환용) |
| `fw` | string | Y | 펌웨어 버전 |
| `channels` | array | N | 채널 목록. 없으면 v1.1 단일 채널 모드 |
| `channels[].ch` | integer | Y | 채널 인덱스 |
| `channels[].sensor` | string | Y | 해당 채널 센서 모델 |
| `channels[].label` | string | N | 사람이 읽을 수 있는 라벨 |

**버전 판정**: `channels` 배열 존재 → v1.2. 없으면 v1.1.

### (3) `"t":"c"` — 캘리브레이션 ACK

```json
{"t":"c","ch":0,"p0":101325}
```

| 필드 | 타입 | 필수 | 설명 |
|------|------|------|------|
| `ch` | integer | N | 캘리브된 채널. 생략 시 `0`. |
| `p0` | integer | Y | 영점 기준 압력 (Pa) |

### (4) `"t":"e"` — 에러

```json
{"t":"e","ch":1,"msg":"sensor_disconnected"}
```

`ch` 추가 (선택). 생략 시 전체 장치 에러.

---

## 브라우저 → 펌웨어

### (1) `{"t":"ping"}` — 변경 없음

### (2) `{"t":"calib","ch":0}` — 채널별 캘리브 요청

```json
{"t":"calib","ch":0}
```

`ch` 생략 시 전체 채널 일괄 캘리브. 펌웨어는 채널별로 `"t":"c"` ACK 각각 회신.

### (3) `{"t":"cfg","rate":200}` — 변경 없음

전체 채널 동일 주기 적용. 채널별 주기 분리는 현 단계 불필요.

---

## 하위 호환 정리

| 시나리오 | 결과 |
|----------|------|
| v1.2 파서 ← v1.1 펌웨어 (ch 없음) | `ch` 기본값 0, 정상 동작 |
| v1.2 파서 ← v1.0 펌웨어 (t 없음) | 기존 v1.0 폴백 경로 유지 |
| v1.1 파서 ← v1.2 펌웨어 (ch 있음) | `ch` 무시, `p`/`T`/`ts` 정상 수신 (단일 채널로 취급) |
| 보일 실험 (단일 센서) | hello에 `channels` 없음 → v1.1 모드, 기존 코드 그대로 |

## 에뮬레이터 모드 전환

에뮬레이터 CLI 에 `--mode` 플래그 추가:

```
node emulator.js                  # 기본: 보일 (ch 0 단일)
node emulator.js --mode dalton    # 돌턴 (ch 0 + ch 1)
```

돌턴 모드 키 조작:

| 키 | 동작 |
|----|------|
| ↑↓ | ch 0 (B) 압력 ±10 kPa |
| ←→ | ch 0 (B) 압력 ±1 kPa |
| W/S | ch 1 (A) 압력 ±10 kPa |
| A/D | ch 1 (A) 압력 ±1 kPa |
| r | 전체 리셋 (101.3 kPa) |
| i | 주입 시뮬 (ch 1 → 0, A→B 기체 이동 시나리오) |
| q | 종료 |
