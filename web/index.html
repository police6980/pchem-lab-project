🔑 AI 튜터 설정 (선택)

AI 튜터와 대화하려면 Anthropic API 키가 필요합니다. 키는 브라우저 세션에만 저장되며 외부 서버로 전송되지 않습니다. API 키 없이도 실험은 모두 사용 가능하지만 AI 튜터 기능은 비활성됩니다.

(저장된 키 없음 — AI 튜터 비활성)
API 키 발급 방법
  1. Anthropic Console에 가입
  2. 좌측 메뉴 → API Keys → Create Key
  3. 생성된 키(sk-ant-로 시작)를 위 칸에 붙여넣기
  4. 결제 수단 등록 필요 (최소 $5 크레딧)
